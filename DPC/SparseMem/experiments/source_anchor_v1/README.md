# 来源锚点构建：开发原型

本原型保留 SparseMem 原记忆、L0/L1/L2、原文与原索引条目。每个记忆块额外选择至多两条原文句子作为检索入口，优先覆盖不同原始发言；入口带词项、时间、会话及可核对的原文偏移。词项只是检索线索，不是可靠实体识别，也不推断跨会话身份或事实关系。句子原文不改写，不读取问题、答案或标注，无新增生成式模型调用。

在准备好的 `records` 与 `archive` 上调用 `build_entries(records, archive, allowed_roles={'user'})`，将返回条目交给现有 `Index.build`。LoCoMo 的说话人不叫 `user`，应按数据设置 `allowed_roles`；默认 `None` 保留所有参与者。它使用现有 `key_sentence` 类型，因此可由现有检索、原文定位与上下文预算处理。不要在此基础上再次叠加原关键句条目，避免重复索引。

这是独立原型，默认流程未接入；目前只验证功能，不代表有效或更省端到端成本。每块最多两句可能漏掉其他事实，句子切分和词频启发式不保证指代正确，也不解决已有证据被漏读。增加索引需要额外嵌入计算、存储和时间，应实测。下一轮如获授权，应同时比较原版、现有关键句版和本版；冻结配置，记录证据完整性、逐题变化、生成与嵌入用量，在未反复调参的题目验证，不能声称模型质量已提升。
